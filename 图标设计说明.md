# 图标设计

使用内置 image_gen 生成，采用绿色便签、完成勾选和金色时钟，与程序的鼠尾草绿和米白界面配色呼应。

- `app-icon.png`：透明背景原始图像。
- `app.ico`：Windows 图标，内含 16、24、32、48、64、128、256 像素七种尺寸。
- `make-icon.ps1`：仅作缩放和格式转换，保留原始透明通道。
- `build.ps1`：将 `app.ico` 嵌入可执行文件；托盘图标从可执行文件读取。
