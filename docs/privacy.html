青笺 QingJian · 隐私说明

更新日期：2026 年 9 月 21 日

青笺是一款待办与截止提醒工具。本说明适用于 Windows 1.3.0 与 Android 0.2.0 同步预览版。旧版 Windows 1.1–1.2 和 Android 0.1 不含跨设备同步。

我们如何处理数据

你输入的待办标题、备注、截止时间、完成状态和显示设置只用于在设备上管理待办和安排提醒。青笺不会将这些内容上传到开发者服务器，不包含广告、统计或第三方跟踪 SDK，也不要求创建账户。

Windows 默认将数据保存到用户的应用数据目录，便携模式保存在程序旁的 data 文件夹。Android 保存在应用私有数据库，并关闭应用自身的系统备份配置。网络权限用于用户主动开启的网盘同步；默认不会连接同步服务器。

可选网盘同步

开启后，青笺将标题、备注、截止时间、完成状态、创建时间、提醒提前量、事项标识及删除标记上传到你配置的 HTTPS WebDAV 目录，文件名为 qingjian-tasks-v1.json。第三方网盘会接收连接所需的账号、应用密码、IP 地址和请求信息，按其政策处理。连接时会创建并清理兼容性探测文件。桌面显示设置、窗口位置、折叠状态、已触发提醒及延后记录不上传。

HTTPS 保护传输，但同步文件没有端到端加密，网盘服务商可以访问其内容。青笺没有开发者同步服务器。账号和应用密码在 Windows 使用当前用户 DPAPI 加密，在 Android 使用 Keystore 保护的密钥加密。请使用应用密码，不要公开凭据。

权限和可见性

Android 通知权限用于发送待办提醒；闹钟和提醒权限用于精确安排时间；开机广播用于设备重启后恢复提醒。拒绝通知权限仍可管理待办，但无法收到系统通知。未允许精确闹钟时，系统可能延迟提醒。

Windows 全信任桌面能力用于 WPF 窗口、托盘、小窗及本地保存。应用不要求管理员权限，也不读取定位、联系人、相册、摄像头或麦克风。

你选择显示的事项会出现在桌面小窗或小组件。通知可能在设备通知栏出现，锁屏展示受操作系统隐私设置控制。

保存、删除与同步

你可以在应用中删除事项。Windows 可能保留上一次保存的本地备份；如需彻底删除，请退出应用后同时删除主数据文件和备份文件。Android 清除应用数据或卸载会删除本地待办。系统备份、设备迁移和厂商服务的行为由其各自政策及设置决定。

同步会传播删除，但为防止旧设备恢复事项，云端仍保留删除标记。同步前的双方副本存放于本机 sync-backups 目录，包含待办内容、不含密码；相同内容去重，当前不自动过期。网盘历史版本还可能保留旧内容。

停用同步不会删除本地或云端文件，也不会清除本机已加密保存的凭据；可在网盘撤销应用密码。彻底删除前应先停用所有设备，再清理各设备的数据、备份和云端文件及历史版本。不要通过 GitHub 问题区公开个人待办、证件、密码或签名密钥。

外部服务

GitHub 下载页面和应用市场由各自运营方提供，相关账号、下载和支付数据受其政策约束。青笺不会自行向这些服务发送你的待办内容。

联系与变更

如有隐私问题，可在 项目问题区联系维护者，仅提供必要的非敏感描述。功能或数据处理方式变化时，本说明会同步更新。
