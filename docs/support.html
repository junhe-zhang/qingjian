青笺 QingJian

一张青笺，记下待办，也记得截止时间。

如何使用

点击「新建」填写事项和截止时间。勾选完成后会划线，再次点击即可恢复。「在桌面显示」决定事项是否出现在桌面小窗或安卓小组件中。

为什么没有收到提醒

Windows 版需要保持运行，关闭主窗口会隐藏到托盘，完全退出或电脑休眠时无法提醒。Android 版请在「提醒设置」允许通知，并检查精确提醒与手机后台运行设置。强行停止应用后，需要重新打开。

我的数据在哪里

Windows 默认使用用户的 LocalAppData/QingJian 目录，便携模式使用程序旁的 data 目录；Android 使用应用私有数据库。数据不会自动同步到其他设备。

反馈问题

在 GitHub 问题区提交问题，说明系统版本、应用版本和复现步骤。请勿附上个人待办、证件、密码或密钥。
